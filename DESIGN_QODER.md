# 太极 Code 界面设计规范 (Qoder 风格)

> 模仿 Qoder 现代桌面 IDE 的 AI 交互界面风格

---

## 1. Qoder 界面特征分析

### 1.1 视觉特点

- **现代简约** — 干净的线条，适度的圆角（终端中用空格模拟）
- **深色主题** — 深色背景，高对比度文字
- **强调色** — 使用蓝色/紫色作为主要强调色
- **清晰层次** — 通过颜色、间距、图标区分信息类型
- **卡片式布局** — 工具调用和结果显示为独立的"卡片"

### 1.2 核心元素

```
┌─────────────────────────────────────────────────────────────┐
│   太极 Code                                    v0.3.0    │  ← 带图标的头部
─────────────────────────────────────────────────────────────┤
│                                                             │
│  👤 用户                                                    │  ← 用户消息标签
│  帮我检查代码质量                                            │
│                                                             │
│  🤖 助手                                                    │  ← 助手消息标签
│  我来分析项目结构...                                         │
│                                                             │
│  ┌─ 🔧 工具调用 ──────────────────────────────────────┐    │  ← 工具卡片
│  │  list_dir(.)                                        │    │
│  │  结果：15 files, 3 dirs                             │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                             │
│  🤖 助手                                                    │
│  发现 3 个问题...                                            │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  ⚡ deepseek-chat  |  3 turns  |  ✓ Ready                  │  ← 状态栏
─────────────────────────────────────────────────────────────┘
  ⚡ > _
```

### 2.2 关键设计元素

| 元素 | 设计 |

| 助手消息 | ` 助手` 标签 + 内容 |
| 工具调用 | 卡片式边框 `┌─ 🔧 tool ─` |
| 工具结果 | 卡片内缩进显示 |
| 状态栏 | `⚡ 模型 | 轮次 | 状态` |
| 输入提示 | `⚡ > ` |

## 3. 配色方案 (Qoder 风格)

### 3.1 主色调

```
┌─────────────────────────────────────────────────────────────┐
│  颜色名称        ANSI    色值        用途                     │
├─────────────────────────────────────────────────────────────┤
│  主强调色        117     #5FAFFF    图标、链接、高亮        │
│  次要强调        141     #AF87FF    工具图标、特殊标记        │
│  成功色          119     #5FD7AF    成功状态、✓ 符号         │
│  警告色          220     #FFAF00    权限请求、⚠ 符号         │
│  错误色          203     #FF5F5F    错误信息、 符号         │
│  用户标签        220     #FFAF00    👤 用户标签              │
│  助手标签        117     #5FAFFF    🤖 助手标签              │
│  工具标签        141     #AF87FF    🔧 工具标签              │
│  卡片边框        238     #444444    工具卡片边框             │
│  次要文字        245     #8A8A8A    状态栏、次要信息         │
│  主文字          15      #FFFFFF    默认文字                 │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 与之前方案对比

| 特性 | Claude Code 风格 | Codex 风格 | Qoder 风格 |
|------|-----------------|-----------|-----------|
| 主色调 | 橙色 (#E06050) | 灰度 | 蓝色 (#5FAFFF) |
| 用户标识 | `> ` 前缀 | `user>` 前缀 | `👤 用户` 标签 |
| 助手标识 | 左侧竖线 `│` | `assistant>` 前缀 | `🤖 助手` 标签 |
| 工具显示 | `⎿ tool args` | ` tool(args)` | 卡片式 `┌─ 🔧 tool ─` |
| 整体感觉 | 终端原生 | 极简克制 | 现代 GUI 感 |

## 4. 组件详细设计

### 4.1 头部

```
⚡ 太极 Code                                    v0.3.0
```

**规范**：
- 左侧：`⚡ 太极 Code`（蓝色 117，粗体）
- 右侧：`v0.3.0`（灰色 245）
- 高度：1 行

### 4.2 用户消息

```
👤 用户
帮我重构这个函数
```

**规范**：
- 标签：`👤 用户`（黄色 220，粗体）
- 内容：默认文字色
- 标签和内容分行显示

### 4.3 助手消息

```
🤖 助手
好的，我来分析代码结构。
```

**规范**：
- 标签：`🤖 助手`（蓝色 117，粗体）
- 内容：默认文字色，Markdown 渲染
- 标签和内容分行显示

### 4.4 工具调用卡片

```
┌─ 🔧 read_file ─────────────────────────────────────┐
│  main.go:1-100                                      │
│  328 lines total                                    │
─────────────────────────────────────────────────────┘
```

**规范**：
- 边框：灰色 238
- 标题栏：`🔧 tool_name`（紫色 141）
- 内容：缩进 2 空格
- 宽度：终端宽度 - 4

### 4.5 权限请求

```
⚠ 权限请求

需要执行：write_file(main.go)

是否允许？[y/n/a]
```

**规范**：
- 图标：`⚠`（黄色 220）
- 文字：黄色
- 独立显示，需要用户确认

### 4.6 状态栏

```
⚡ deepseek-chat  |  3 turns  |  ✓ Ready
```

**规范**：
- 左侧：`⚡ 模型名`（蓝色 117）
- 分隔符：` | `（灰色 245）
- 中间：轮次信息
- 右侧：状态（✓ Ready /  Working / ⚠ Plan）

### 4.7 输入区

```
⚡ > _
```

**规范**：
- 前缀：` > `（蓝色 117）
- 光标：反向块光标

## 6. 实现要点

### 6.1 需要修改的文件

| 文件 | 修改内容 |
|------|----------|
| `internal/ui/tui.go` | 颜色方案、渲染函数、布局逻辑 |

### 6.2 核心变更

1. **颜色变量重定义**
   ```go
   // Qoder 风格配色
   accentBlue = lipgloss.Color("117")    // 主强调色
   accentPurple = lipgloss.Color("141")  // 工具色
   userYellow = lipgloss.Color("220")    // 用户标签
   assistantBlue = lipgloss.Color("117") // 助手标签
   ```

2. **渲染函数重写**
   - `renderUserBlock`: 改为 `👤 用户` 标签 + 内容
   - `renderAssistantBlock`: 改为 `🤖 助手` 标签 + 内容
   - `renderToolCallBlock`: 改为卡片式 `┌─ 🔧 tool ─┐`
   - `renderHeader`: 改为 `⚡ 太极 Code` + 版本号

3. **状态栏重设计**
   - 显示 `⚡ 模型 | 轮次 | 状态`
   - 状态图标：✓ Ready / ⏳ Working / ⚠ Plan
